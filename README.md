# 極速撤離 Extract-Lite

一款諷刺風格的「搜打撤」3D 網頁小遊戲（Three.js）。

## 概念
從你自己的基地出發 → 進入隨機生成的關卡（五種主題）→ 搜刮物資、打倒敵人 → 在時限內搭直升機撤離。撤離成功才能把戰利品帶回家；死掉或錯過直升機，帶進去的裝備就可能沒了。

## 線上遊玩
👉 https://hl2dm.github.io/extract-lite/

也可以下載後直接雙擊 `index.html` 遊玩（免安裝）。

## 玩法
- **基地（可走動）**：走到設施前按 **E** 互動
  - 置物櫃 → 倉庫｜販賣機 → 商店｜工作台 → 升級｜老K → 任務｜展示櫃 → 戰利品｜地圖桌 → 選地圖出擊
  - **Tab / M** 或右上「📋 選單」開快速選單
- **出擊**：搜箱子、撿地上的物資（發光的小物件，靠近按 E 直接撿，背包滿了就撿不了）、找鑰匙開門、注意隨機事件，找到撤離點搭直升機
- 成功撤離後在基地賣掉戰利品、買裝備、升級基地

## 操作
| 動作 | 電腦 | 觸控 |
|---|---|---|
| 移動 | WASD | 左側搖桿 |
| 轉視角 | 滑鼠 | 右側拖曳 |
| 射擊 | 左鍵 | 開火鍵 |
| 互動 / 搜刮 | E | E 鍵 |
| 背包 / 選單 | Tab（基地：Tab / M） | 📋 按鈕 |
| 換彈 | R | R 鍵 |
| 跑步 | Shift | 跑 鍵 |

## 技術
純 HTML + JavaScript，Three.js r160，無需建置。
